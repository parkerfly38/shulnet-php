Banner Messages

The Banner Message System allows administrators to create and manage important announcements and notifications that display to members when they log in or visit their dashboard.

Overview

Banners are highly visible messages that appear at the top of pages to communicate important information to your members. They can be used for:

  • Important announcements (e.g., office closures, holiday schedules)
  • Urgent alerts (e.g., weather-related cancellations)
  • Success messages (e.g., successful event registrations)
  • Time-sensitive information (e.g., upcoming deadlines)
  • Call-to-action messages with links to specific pages or actions
Note: Banner management is only available to administrators. Regular members can view and interact with banners but cannot create or edit them.

Viewing Banners (All Users)

As a member, you'll see active banners when you:

  • Log in: Banners configured to show on login will appear immediately
  • Visit your dashboard: Dashboard banners will appear at the top of the page
  • Use the mobile app: Banners are delivered via the API and displayed in the app

Banner Types

Banners come in four types, each with distinct colors to indicate their purpose:

Type Color Use Case
Info Blue General information and announcements
Success Green Positive updates or confirmations
Warning Yellow Important notices that need attention
Error Red Critical alerts or urgent messages

Interacting with Banners

Depending on the banner configuration, you can:

  • Dismiss: Click the "×" button to hide banners you've already read
  • Take Action: Click action buttons to navigate to relevant pages or resources
  • View Automatically: Some banners auto-hide after a specified duration
Tip: Once you dismiss a banner, it won't appear again. Make sure you've read important information before dismissing!

Managing Banners (Administrators)

Administrators can create, edit, and manage banners from the admin dashboard.

Accessing Banner Management

  1. Navigate to Banners

    From the admin dashboard, go to Admin > Banners in the main menu.

  2. View Banner List

    You'll see a list of all banners with their status, type, and target audience.

Creating a New Banner

  1. Click "Create New Banner"

    On the banner management page, click the button to create a new banner.

  2. Enter Basic Information

    Fill in the following required fields:

    • Title: A short headline for the banner (e.g., "Office Closed Tomorrow")
    • Message: The main content of the banner. HTML is supported for formatting.
    • Type: Select Info, Success, Warning, or Error

  3. Choose Target Audience

    Select who should see this banner:

    • Members: Display to congregation members only
    • Students: Display to students only (if using school features)
    • Parents: Display to parents only (if using school features)
    • All: Display to everyone

  4. Set Display Schedule

    Control when the banner appears:

    • Start Date: When the banner should start displaying
    • End Date: (Optional) When the banner should stop displaying
    • Display Duration: How long (in seconds) the banner shows before auto-hiding

  5. Configure Display Options

    Check the appropriate boxes:

    • Is Active: Enable or disable the banner
    • Is Dismissible: Allow users to dismiss the banner
    • Show on Login: Display immediately when users log in
    • Show on Dashboard: Display on the user's dashboard
    • Send as Push Notification: Send to mobile app users (if enabled)

  6. Add Action Button (Optional)

    Include a call-to-action button:

    • Action Button URL: Where the button should link to
    • Action Button Text: What the button should say (e.g., "Learn More", "Register Now")

  7. Save the Banner

    Click "Save" to create the banner. It will immediately be active based on your settings.

Editing a Banner

  1. Locate the Banner

    Find the banner you want to edit in the banner list.

  2. Click "Edit"

    Click the edit button next to the banner.

  3. Make Changes

    Update any fields as needed.

  4. Save Changes

    Click "Update" to save your changes. They'll take effect immediately.

Toggling Banner Status

You can quickly enable or disable banners without editing them:

  1. Find the Banner

    Locate the banner in the list.

  2. Click Toggle Button

    Use the toggle switch or "Activate/Deactivate" button to change the status.

Tip: Deactivating a banner is useful when you want to temporarily hide it without deleting it. You can reactivate it later.

Deleting a Banner

  1. Locate the Banner

    Find the banner you want to delete.

  2. Click "Delete"

    Click the delete button.

  3. Confirm Deletion

    Confirm that you want to permanently delete the banner.

Warning: Deleting a banner is permanent and cannot be undone. All statistics will also be deleted.

Banner Statistics

Administrators can track how users interact with banners:

Available Metrics

Metric Description
View Count How many times the banner was displayed to users
Click Count How many times users clicked the action button
Dismiss Count How many times users dismissed the banner
Click-Through Rate Percentage of views that resulted in clicks
Dismiss Rate Percentage of views that were dismissed

Viewing Statistics

  1. Open Banner Details

    Click on a banner in the list to view its details.

  2. Navigate to Statistics

    Look for the "Statistics" or "Analytics" section in the banner details.

  3. Review Metrics

    View engagement metrics to understand how users are interacting with the banner.

Best Practices

Creating Effective Banners

  • Be Concise: Keep messages short and focused. Users should understand the message at a glance.
  • Choose the Right Type: Match the banner type to the message urgency and importance.
  • Use Action Buttons Wisely: Include clear calls-to-action when you want users to take specific steps.
  • Set Appropriate Dates: Use start and end dates to automatically manage banner visibility.
  • Target the Right Audience: Only show banners to users who need to see them.

When to Use Each Banner Type

Type Good Use Cases Avoid Using For
Info (Blue) New features, general updates, reminders Urgent issues, errors
Success (Green) Completed actions, positive news, achievements Future events, warnings
Warning (Yellow) Important deadlines, potential issues, changes Good news, routine updates
Error (Red) System outages, critical alerts, security issues Regular announcements, minor issues

Managing Multiple Banners

  • Limit Active Banners: Too many banners can overwhelm users. Keep only the most important ones active.
  • Prioritize by Urgency: Use the "Error" type sparingly for only the most critical messages.
  • Update Regularly: Remove or deactivate outdated banners promptly.
  • Test Before Publishing: Preview banners to ensure they display correctly.

Mobile App Integration

Banners are automatically available in the ShulNET mobile app through the API.

Push Notifications

When enabled, banners can trigger push notifications to mobile users:

  • Check "Send as Push Notification" when creating the banner
  • Mobile users will receive a notification even when not actively using the app
  • The banner will also display within the app when they open it
Note: Push notifications require proper mobile app configuration. Contact your administrator if this feature isn't working.

WordPress Integration

If your organization uses a WordPress website, the ShulNET WordPress plugin can display banners on your public site.

Benefits

  • Consistent messaging across all platforms
  • Automatic updates from ShulNET
  • No need to duplicate content
  • Members see the same important messages everywhere
Note: WordPress integration requires the ShulNET Banner Feed plugin to be installed and configured on your WordPress site.

Troubleshooting

Banner Not Displaying

If a banner isn't showing to users, check:

  • Is Active: Ensure the banner is activated
  • Dates: Verify the current date is between start and end dates
  • Target Audience: Confirm the user is in the selected audience
  • Display Settings: Check that "Show on Dashboard" or "Show on Login" is enabled

Users Can't Dismiss Banner

If users are unable to dismiss a banner:

  • Verify that "Is Dismissible" is checked in the banner settings
  • Some banners may be intentionally non-dismissible for critical messages

Statistics Not Updating

If statistics appear incorrect:

  • Statistics are updated in real-time, but may have a slight delay
  • Refresh the page to see the latest data
  • Ensure users are properly authenticated when viewing banners
