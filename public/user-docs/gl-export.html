Chart of Accounts & GL Export

Map ShulNET income to your general ledger accounts, then export payments as a GL batch your bookkeeper can import into accounting software such as QuickBooks.

Chart of Accounts

Navigate to Chart of Accounts under Settings in the admin menu (/admin/chart-of-accounts).

Each account has a code, a name, a type (Revenue, Expense, Asset, Liability or Equity), a sort order and an active status. Mark an account inactive when you stop using it rather than deleting it.

Default Accounts

Your administrator can load a starting set of synagogue revenue accounts, including:

  • 4000 Membership Dues Revenue
  • 4100 Hebrew School Tuition
  • 4200 Donations - General, 4210 Building Fund, 4220 Memorial
  • 4300 Event Revenue
  • 4400 Cemetery Plot Sales, 4410 Cemetery Services
  • 4500 High Holiday Seats

Edit the codes to match your own ledger.

Assigning Accounts to Invoice Items

When you create or edit an invoice, choose a GL account for each line item. Payments are allocated to these accounts in the export, so items without an account will not appear correctly in the batch.

Exporting a GL Batch

  1. Open GL Batch Export

    Go to Reports and choose GL Batch Export.

  2. Choose the date range

    Select the start and end dates of the payments to include. Optionally enter a batch number, or let ShulNET generate one.

  3. Review the summary

    The summary shows totals by account so you can check them before exporting.

  4. Export

    Download the Excel file. Each row has the batch number, transaction date, GL account code and name, debit and credit amounts, invoice number, member, payment method and transaction ID.

Split payments: When a payment covers an invoice with several line items, ShulNET divides it across their GL accounts in proportion to each item's amount.
