PDF Templates

PDF Templates turn reusable documents, such as yahrzeit donation acknowledgments, honor letters or certificates, into fill-in-the-blank forms. Enter the values and ShulNET produces a finished PDF.

Accessing PDF Templates

Go to /admin/pdf-templates. The list can be filtered by category and status and searched by name.

Creating a Template

  1. Basic information

    Click Create Template and enter a name (for example "Yahrzeit Donation Letter"), a slug (for example yahrzeit-donation-letter), a description and a category: General, Letter, Invoice or Form.

  2. Define the fields

    Under Available Fields, click Add Field for each value the document needs. Give each field a label (for example "Deceased Name"), a field name (for example deceased_name), a type (Text, Text Area, Number or Date), an optional default value, and whether it is required.

  3. Write the HTML content

    Write the document in HTML. Insert a field by placing its name in double curly braces.

    Dear {{ donor_name }},<br> Thank you for your gift in memory of {{ deceased_name }}.

  4. Save

    Click Create PDF Template.

Generating a PDF

  1. Open the template from the list
  2. Under Fill Template Fields, enter a value for each field
  3. Click Preview to check the result, then Generate PDF to download it
Letterhead: The PDF header logo and footer text are set by an administrator in General Settings.
