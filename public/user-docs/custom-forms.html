Custom Forms

Custom Forms let you build simple forms, such as volunteer sign-ups, kiddush sponsorship requests or contact forms, and embed them on any web page. Submissions are collected in ShulNET.

Accessing Custom Forms

Navigate to Custom Forms in the admin menu (/admin/forms).

Creating a Form

  1. Start a new form

    Click Create Form.

  2. Enter form details

    Give the form a Form Name and an optional description, and check Form is active and accepting submissions.

  3. Add fields

    Under Form Fields, add each field and choose its type: Text, Text Area, Date or Select (a dropdown with options you list). Mark fields as required where needed.

  4. Check the preview

    The Preview panel shows the form as visitors will see it.

  5. Save

    Click Create Form.

Embedding a Form

  1. Open the form from the Custom Forms list
  2. Under Embeddable Form Code, click Copy Code
  3. Paste the code into any web page, such as a page in the HTML Publisher or your WordPress site

Visitors do not need a ShulNET account to submit an embedded form.

Viewing Submissions

Each form's page shows its Total Submissions. Click View All Submissions to read the responses.

Closing a form: Edit the form and uncheck Form is active to stop accepting submissions without losing the responses you have already received.
